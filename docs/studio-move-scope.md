# ขอบเขตระบบย้ายสตูดิโอที่ตกลงในแชต

สถานะเอกสาร: แนวทางสำหรับ implementation ถัดไป ยังไม่ใช่ฟีเจอร์ที่ทำเสร็จ

เป้าหมาย: ตรวจของก่อนย้าย ตรวจรับปลายทาง และใช้รายการที่รับถึงออฟฟิศใหม่เป็นคลังสำหรับทำงานต่อ โดยอ้างอิง Unit ID เดิมตลอด ไม่สร้างสำเนาอุปกรณ์อีกชุด

- เก็บบัญชีอุปกรณ์เดิมเป็นข้อมูลตั้งต้นของรอบย้าย พร้อมจำนวนและสภาพ ณ เวลานั้น
- ระบุปลายทาง: ออฟฟิศใหม่ / เก็บที่เดิม / ส่งคืน / รอจำหน่าย / รอตัดสินใจ
- เก็บรหัสกล่อง ผู้แพ็ก ผู้ส่ง ผู้รับ เวลา และตำแหน่งเก็บใหม่
- รูปประจำอุปกรณ์กับรูปตรวจสภาพขาออก–ขาเข้าเป็นคนละรายการ เก็บหลายรูปพร้อมผู้อัปโหลดและเวลา
- สถานะการขนย้ายแยกจากสภาพอุปกรณ์ เช่น ส่งออกแล้ว + ต้องซ่อม
- ของที่เลือกย้ายแต่ยังไม่รับถึงอยู่ในรายการรอตรวจรับ และยังไม่พร้อมหยิบจากคลังใหม่
- ยืนยันรับเข้าแล้วจึงปรับสถานที่ปัจจุบันของ Unit และแสดงในคลังออฟฟิศใหม่
- ของเสียหายที่รับถึงเข้าคลังใหม่ด้วยสภาพตามจริง แต่ไม่ถูกระบุว่าพร้อมใช้งาน
- หลังย้ายเสร็จใช้คลังใหม่เป็นหน้าหลัก รอบย้ายและข้อมูลเดิมยังเปิดตรวจประวัติได้
- รองรับ S/N รายชิ้น และจำนวนรวมสำหรับของเหมือนกันที่ไม่มี S/N โดยยังผูก Unit ID ภายใน
- ใช้คลังใหม่นี้กับเตรียมออกกองต่อ พร้อมเงื่อนไขการพร้อมใช้งานและการติดกอง

ก่อนทำ schema ต้องยืนยันความถูกต้องของ Unit ID / S/N และแก้การ sync จาก master ตามผลรีวิว การรับเข้าต้องบันทึกซ้ำได้โดยไม่เพิ่มจำนวนหรือประวัติซ้ำเมื่อเน็ตขาดแล้วผู้ใช้ลองใหม่
